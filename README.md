# vybetechlabs-blip

This account holds projects I built for my own knowledge and as proofs of concept. Each README says what the project does and how to run it from a fresh clone.

Each of the six repositories below has a section in its README called "How AI was used" that says which parts Claude Code built and which decisions and checks were mine.

## Repositories
- **[grounded-notes](https://github.com/vybetechlabs-blip/grounded-notes)** answers questions from 25 synthetic documents, cites the file and heading for every answer, and refuses instead of guessing when the documents do not hold the answer. The committed eval has 19 cases and scores 100% on all three of its metrics.
- **[outreach-lint](https://github.com/vybetechlabs-blip/outreach-lint)** scores each cold-email draft from 0 to 100 against 14 configurable rules. It also compares drafts with each other, to catch repeated openers and closers across a batch. It runs without an API key.
- **[company-briefer](https://github.com/vybetechlabs-blip/company-briefer)** turns a domain into a pre-call research brief built only from the company's public marketing pages. It reads at most 8 fixed paths, honors robots.txt and removes emails and phone numbers before it stores anything. It works without a key, and the suite has 115 tests.
- **[supabase-support-desk](https://github.com/vybetechlabs-blip/supabase-support-desk)** is a support desk on Supabase. Customers file tickets, agents work them, row level security decides who sees what, and an Edge Function triages each new ticket. A troubleshooting lab reproduces four Supabase problems, two row level security bugs and two performance problems, each with a fix and a test. It runs on a local stack only.
- **[voice-receptionist](https://github.com/vybetechlabs-blip/voice-receptionist)** is an AI receptionist for one fictional HVAC business, built on Pipecat. Guards check each tool call against what the caller actually said, so an invented name or number never reaches the calendar. The eval runs 15 scripted callers 3 times each. gpt-6-luna passes 45 of 45 runs and a local gpt-oss:20b passes 43. Phase 1 is complete and the public demo is not built yet.
- **[enquiry-to-quote](https://github.com/vybetechlabs-blip/enquiry-to-quote)** turns a service inquiry for a fictional cleaning business into a priced draft reply that waits for a person to approve it. A language model may read the inquiry, but a rate card sets every price. On two held-out sets of 15 synthetic inquiries, claude-haiku-5-5 averaged 15 of 15 on both over three passes, and a local gpt-oss:20b averaged 14.0 and 14.7. Its approval queue and eval runs come from [smb-agent-kit](https://github.com/vybetechlabs-blip/smb-agent-kit), a small kit I pulled out of this project so the next agent starts from them.
